# Create Networks

Pricing and services page for **Create Networks** — a web design and digital services brand.

**Live site:** https://createnetworks.netlify.app  
**Status:** Work in progress — single pricing/services page, full site redesign pending.

## Stack

Static HTML/CSS/JS. Zero dependencies, no build step.

- `index.html` — live pricing page
- `style.css` — all styles for the current page
- `utilities.css` — shared utility classes (also used by original.html)
- `original.html` — earlier version, linked from footer, not indexed

## Running locally

Open `index.html` directly in a browser — no server needed.

## Deployment

Connected to Netlify. Any push to `main` auto-deploys.
